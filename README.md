# 메모장 (웹앱)

iPad 에서 txt 파일을 열어 읽고, 고치고, 저장하는 메모장입니다.
설치(사이드로딩) 없이 Safari 의 **홈 화면에 추가**로 앱처럼 씁니다. 7일마다 다시 깔 필요가 없고, 인터넷이 없어도 열립니다.

## 올리는 방법 (GitHub Pages)

1. GitHub 에서 새 저장소를 만듭니다 (예: `memo`). **Public** 이어야 무료 Pages 가 됩니다.
2. 이 폴더의 파일을 모두 올립니다 (`index.html` 이 저장소 맨 위에 있어야 합니다).
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
5. iPad **Safari** 로 그 주소를 열고 → 공유 버튼 → **홈 화면에 추가**.

## 업데이트할 때

파일을 고쳐 올린 뒤 `sw.js` 맨 위의 `VERSION` 숫자를 하나 올려 주세요 (`memo-v1` → `memo-v2`).
인터넷이 연결된 상태에서 앱을 한 번 껐다 켜면 새 버전으로 바뀝니다.

## 저장 방법

웹앱은 파일 앱의 원본 파일에 직접 쓸 수 없습니다. 그래서 저장하면 **공유 화면**이 열립니다.

- **파일에 저장** → 원래 폴더 → 같은 이름으로 저장 → iPad 가 **대치**할지 물으면 대치 → 원본이 바뀝니다.
- 새 문서·다른 이름으로 저장은 먼저 파일 이름을 묻고, 그다음 폴더를 고릅니다.
- 문자셋(UTF-8 / ANSI(CP949) / UTF-16 …)과 줄 구분(CRLF / LF / CR)은 아래 상태줄에서 고릅니다. 건드리지 않으면 원래 파일의 설정 그대로 저장됩니다.

열었거나 저장한 문서는 앱 안에 사본으로 보관되어(최근 30개) 첫 화면 **최근 문서**에서 다시 열 수 있습니다.
앱을 닫아도 쓰던 문서는 자동으로 보관되어 다시 켜면 그대로 이어집니다.

## 기능

- 파일을 열면 **읽기 모드** (단락을 누르면 **단락 복사**), [편집] 버튼으로 편집 모드. 새 문서는 바로 편집 모드.
- 찾기: 다음/이전/모두 찾기, 대·소문자 구분, 처음부터 다시 찾기. `{{user}}` 같은 특수문자도 글자 그대로 찾습니다.
- 바꾸기: [바꾸기] 체크 → 바꿀 내용 칸, 위로/아래로 바꾸기(가장 가까운 것 하나), 모두 바꾸기.
- 실행 취소 / 다시 실행, 글자 크기 조절.
- 나가기 때 저장 확인: `"파일이름.txt"을 저장할까요?` / `변경한 내용을 "파일이름.txt"에 저장할까요?` → 예 / 아니오 / 취소.
- Split View 에서 파일 앱의 txt 를 끌어다 놓아도 열립니다.

## 키보드 단축키

| 동작 | 단축키 |
|---|---|
| 새로 만들기 / 열기 | ⌘N / ⌘O |
| 저장 / 다른 이름으로 저장 | ⌘S / ⇧⌘S |
| 찾기 / 바꾸기 | ⌘F / ⌥⌘F (또는 Ctrl+H) |
| 다음 찾기 / 이전 찾기 | ⌘G / ⇧⌘G (찾기 칸에서 Enter / ⇧Enter) |
| 실행 취소 / 다시 실행 | ⌘Z / ⇧⌘Z (또는 ⌘Y) |
| 읽기 ↔ 편집 | ⌘E |
| 나가기 | ⌘W |
| 글자 크게 / 작게 / 기본 | ⌘= / ⌘− / ⌘0 |
| 찾기 닫기 | Esc |

⌘ 대신 Ctrl 도 됩니다. Safari 탭에서 열면 ⌘N·⌘W 같은 일부 단축키를 Safari 가 먼저 가져갈 수 있으니 홈 화면 앱으로 쓰는 것을 권장합니다.

## 웹앱이라 안 되는 것

- 파일 앱에서 txt 를 눌렀을 때 기본으로 열리는 앱이 될 수 없습니다 (앱 안의 [열기]로 엽니다).
- 원본 파일에 바로 덮어쓰기 불가 → 공유 화면의 "파일에 저장"으로 대치.
- 앱이 스스로 꺼질 수 없어 [나가기]는 첫 화면으로 돌아갑니다.

## 파일 구성

모든 파일이 저장소 맨 위에 그대로 있습니다(폴더 없음 — iPad 에서 올리기 쉽게).

```
index.html             화면
app.css                디자인
app.js                 화면 동작
codec.js               문자셋·줄 구분 읽기/쓰기
search.js              찾기·바꾸기
history.js             실행 취소 기록
store.js               앱 안 보관함
sw.js                  오프라인 실행
manifest.webmanifest   홈 화면 앱 설정
*.png                  아이콘
```
